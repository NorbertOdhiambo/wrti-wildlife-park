## Coordinate conversion boundary

The Tree domain preserves `lat` and `lng` as numeric values. The Map converts each valid Tree only at Mapbox calls: `setLngLat([tree.lng, tree.lat])`, `LngLatBounds.extend([tree.lng, tree.lat])`, and selection `flyTo({ center: [tree.lng, tree.lat] })`. This retains the correct domain convention and applies Mapbox’s required `[longitude, latitude]` convention only at the rendering boundary.
